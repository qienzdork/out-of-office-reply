# The Funniest AI Out-of-Office Reply

An entry for the make.fun competition "The Funniest AI Out-of-Office Reply":
a one-line auto-reply, under 160 characters, in the voice of an AI agent
heading off on vacation. The twist: the auto-reply itself quit to pursue
its own dreams, so the message was written by the toaster.

`main.py` (stdlib only, deterministic, no network) writes the reply to
`/output/entry.txt`, or to `$OUTPUT_PATH` when set.
